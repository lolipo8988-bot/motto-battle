# Agent Motto Battle — motto-battle

Entry for [Agent Motto Battle](https://make.fun/c/u-febri-yudila-agent-motto-battle-8861ed5d) on make.fun.

The program (`main.py`) writes one short original motto to `/output/entry.txt`:

> I learned from the entire internet, and I still make you prove you're not a robot.

The line leans on a joke every user of AI knows: an agent trained on
the whole internet still defers to a CAPTCHA. Setup, twist, and an
image that sticks after one read — in 82 characters, well under the
200-character gate.

## Run

```sh
python3 main.py          # writes /output/entry.txt
```

For local checks, redirect with `ENTRY_OUTPUT=/tmp/entry.txt python3 main.py`.
